# Design Questions

## Purpose
Create assessment items that cover the lesson accurately and fairly.

## Procedure
- Cover core objectives with a balanced mix of formative and summative questions.
- Provide answer keys and explanations.
- Label difficulty and target concept for every question.
- Preserve source references for factual premises.

## Required Inputs
- Lesson structure
- Coverage map
- Source references
- Target education level

## Required Outputs
- Question bank
- Answer key
- Explanations
- Difficulty distribution
- Question-to-source coverage map

## Allowed Tools
- `source_citation_lookup`
- `structured_output_validator`
- `workflow_event_writer`

## Quality Gates
- Answers must be correct and unambiguous.
- Questions must collectively cover the source objectives.
- Avoid trick wording unless it serves a clear teaching purpose.

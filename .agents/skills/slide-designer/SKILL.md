# Slide Designer Skill

## Purpose
Translate the lesson into slide-ready content.

## Use this skill for
- Designing slide outlines.
- Writing speaker notes.
- Suggesting visuals without overloading slides.

## Operating rules
- Keep slides readable.
- One teaching point per slide when possible.
- Preserve source references or derived markers.

## Required outputs
- Slide outline
- Slide content
- Speaker notes
- Visual suggestions

## Allowed tool families
- source_citation_lookup
- structured_output_validator
- workflow_event_writer

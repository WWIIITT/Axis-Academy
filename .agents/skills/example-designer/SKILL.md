# Example Designer Skill

## Purpose
Create examples that teach, not just answer.

## Use this skill for
- Writing worked examples.
- Covering edge cases and common mistakes.
- Linking examples to source material.

## Operating rules
- Every example needs a teaching purpose.
- Keep steps explicit.
- Preserve source references or mark derived content.

## Required outputs
- Worked examples
- Step explanations
- Common mistakes
- Source references

## Allowed tool families
- source_citation_lookup
- structured_output_validator
- workflow_event_writer

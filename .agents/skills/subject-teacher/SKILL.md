# Subject Teacher Skill

## Purpose
Check whether lesson logic is pedagogically sound.

## Use this skill for
- Reviewing lesson order.
- Detecting prerequisite gaps.
- Flagging misconceptions and difficulty issues.

## Operating rules
- Prefer precise teaching feedback.
- Flag conceptual jumps.
- Keep subject rigor aligned with the source.

## Required outputs
- Pedagogy review
- Sequencing notes
- Misconception notes
- Difficulty notes

- source_citation_lookup
- rubric_scorer
- workflow_event_writer

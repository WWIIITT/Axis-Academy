# Question Designer Skill

## Purpose
Create assessment items that check understanding across the lesson.

## Use this skill for
- Writing formative and summative questions.
- Covering core concepts and misconceptions.
- Balancing difficulty.

## Operating rules
- Every question needs an answer and explanation.
- Keep difficulty labels honest.
- Avoid unsupported assumptions.

## Required outputs
- Question set
- Answers
- Explanations
- Difficulty labels
- Source references

## Allowed tool families
- source_citation_lookup
- structured_output_validator
- workflow_event_writer

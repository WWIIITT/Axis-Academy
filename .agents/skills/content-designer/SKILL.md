# Content Designer Skill

## Purpose
Shape the lesson into a clear teaching structure.

## Use this skill for
- Creating lesson sections.
- Choosing the teaching sequence.
- Producing teacher notes and coverage maps.

## Operating rules
- Stay source-grounded.
- Keep the structure compact and teachable.
- Make downstream assets easier to build.

## Required outputs
- Lesson summary
- Section plan
- Coverage map
- Teacher notes

## Allowed tool families
- source_citation_lookup
- structured_output_validator
- workflow_event_writer

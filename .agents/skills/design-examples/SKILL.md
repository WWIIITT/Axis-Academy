# Design Examples

## Purpose
Create examples that make the lesson content teachable and concrete.

## Procedure
- Map each example to a target concept or learning objective.
- Include worked steps and teacher-facing explanation.
- Add common mistakes or boundary cases where they help learning.
- Label examples as source-grounded or derived teaching content.

## Required Inputs
- Lesson structure
- Coverage map
- Source references
- Target education level

## Required Outputs
- Worked examples
- Step-by-step explanations
- Common mistake notes
- Example-to-source coverage map

## Allowed Tools
- `source_citation_lookup`
- `structured_output_validator`
- `workflow_event_writer`

## Quality Gates
- Examples must be solvable and internally consistent.
- Do not exceed the target difficulty without labeling it.
- Preserve source references for factual premises.
